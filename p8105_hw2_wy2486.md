**Read and clean the *MCI Amyloid* data**

``` r
mci_amyloid_df =
  read_csv(
    "./datahw2/data_mci/mci_amyloid.csv",
    skip = 1,
    na = c("", "NA", ".")
  ) |>
  janitor::clean_names() |>
  pivot_longer(
    baseline:time_8,
    names_to = "time",
    values_to = "amyloid_42_40"
  ) |>
  mutate(
    time = case_match(
      time,
      "baseline" ~ 0,
      "time_2" ~ 2,
      "time_4" ~ 4,
      "time_6" ~ 6,
      "time_8" ~ 8
    )
  )
```

The MCI amyloid dataset was imported using `read_csv()`. The first row
was skipped because it contains descriptive information rather than
variable names. Blank values, `"NA"`, and `"."` were treated as missing
values, and variable names were standardized using `clean_names()`. The
original dataset was not fully tidy because amyloid 42/40 measurements
at different follow-up times were stored in separate columns. Therefore,
`pivot_longer()` was used to reshape these repeated measurements into a
single `time` variable and a single `amyloid_42_40` variable. The `time`
variable was then recoded using `mutate()` so that baseline and
follow-up visits were represented numerically as 0, 2, 4, 6, and 8.
